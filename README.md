# Math Lab ครูคุ้ม (หน้ารวมเว็บ)
1. สร้าง repository ชื่อ `mathdevth.github.io` (ต้องตรงกับชื่อบัญชี) แบบ Public
2. อัปโหลด index.html → Commit
3. Settings → Pages → Branch main /(root) → Save
4. เว็บอยู่ที่ https://mathdevth.github.io/
แก้รายการเว็บ: เปิด index.html หาตัวแปร `const S=[` แต่ละการ์ดคือ {t: ชื่อ, d: คำอธิบาย, u: ลิงก์}
